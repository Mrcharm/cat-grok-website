etl-sql-createSQL生成

把已满足 SQL 准入的结构化事实（evidence_card / direct_input）转换为可检核的 SQL 草案；已有草案时按用户反馈或检核问题定向修订。默认 PostgreSQL 方言，支持会话级临时表与运行参数占位符渲染。

把取证事项转换为受控查询计划，调用批准的数据库查询工具，把结果汇总为唯一结构化 evidence_card。每轮最多执行 3 个独立的待查项，支持检查点续跑与用户补充。

证据管理查询规划白名单路由

etl-md-write文档写入

将各阶段产出写入或更新 PLAN.md 与 RECORD.md，并调用 publishArtifact 展示。按模板渲染章节，已有章节原位替换，重复写入幂等、不产生重复内容。

Markdown模板渲染幂等写入

etl-check-ruler校验规则

检核 SQL 并只返回高危与超高危问题；平台工具不可用或未接入时按固定静态规则兜底。不执行 SQL、不改写 SQL，也不把「工具不可用」解释成「SQL 通过」。

安全检核静态兜底风险映射
