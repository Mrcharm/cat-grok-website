# operation-manual

## 1. 技能目标

生成能够让首次使用者独立完成真实工作任务的操作手册。手册不是功能清单，而是“用户培训 + 操作指南 + 实施交付件”。

## 3. 硬性规则

- 已有手册采用保留式更新，不改变原排版、章节编号、页眉页脚、字体、图注和表格风格。
- 手册必须覆盖 PRD 中所有正式功能；原型中的主要功能也必须有操作说明。
- 以用户实际任务顺序组织，不按代码模块或接口顺序堆砌。
- 优先真实截图和真实动图；不得用虚构页面替代真实界面。
- 关键操作尽量“一步一图”；图必须紧跟对应步骤。
- 截图、按钮、菜单、字段名称必须与系统一致。
- 不得跳过参数配置、权限、保存、提交、导出、Git、审批、发布等端到端环节。
- 常见问题采用“现象—原因—处理步骤—注意事项”，不使用密集大表。
- 输出必须可编辑；DOCX 必须逐页渲染检查。

## 4. 图片与证据优先级

1. 平台真实截图；
2. 平台提供的 `.webp` 动图；
3. 从动图提取的关键静态帧；
4. 已确认的高保真原型；
5. 明确标注为“示意”的自绘图。

动图不能稳定显示时，必须保留静态关键帧，不得直接删掉该操作证据。

## 5. 执行流程

### 步骤 0：输入盘点

读取：当前手册、PRD、原型、真实截图/动图、角色权限、系统入口、菜单路径、版本变化和已知问题。

形成：

- 功能覆盖矩阵；
- 截图资源清单；
- 旧章节—新章节映射；
- 缺图与待确认项。

只有核心路径、页面入口或版本基线无法判断时才提问，最多两个关键问题。

### 步骤 1：确定主流程

先画出用户完成任务的端到端主链路。例如 ETL 场景：

> 参数配置 → 系统入口 → 新增脚本 → 选择系统与目标表 → 选择映射/流程设计 → 完成设计 → SQL 预览与验证 → 保存 → Git 提交 → 文档导出/发布

模型设计场景：

> 参数配置 → 逻辑模型模板 → 导入与检核 → 提交审批/数据项联动 → 物理模型设计 → 数据就绪判断 → 审批与 D 模型同步 → 发布集成接口

### 步骤 2：目录组织

已有手册服从原目录。无模板时默认：

1. 快速开始；
2. 平台主流程；
3. 界面布局与全局控制；
4. 按业务模式/用户任务展开的核心操作；
5. 审批、保存、提交、导出与发布；
6. 完整实战案例；
7. 常见问题；
8. 附录：快捷键、图标、资源、动图、名词。

### 步骤 3：编写操作步骤

每组操作采用：

- 步骤标题；
- 操作路径；
- 前置条件；
- 具体操作；
- 系统反馈；
- 检查结果；
- 注意事项；
- 对应截图/动图和图注。

使用 `templates/操作步骤模板.md`。

### 步骤 4：界面说明

复杂平台必须先说明工作台区域：

- 顶部导航/全局操作；
- 左侧活动栏和资源树；
- 中间主编辑区和 Tab；
- 右侧预览/属性/智能辅助；
- 底部结果、日志和测试；
- 状态栏、环境和保存状态。

界面说明不能替代实际操作步骤。

### 步骤 5：状态与异常

步骤说明至少覆盖：

- 初始/空数据；
- 加载中；
- 成功；
- 校验失败；
- 部分成功；
- 导入失败；
- 超时；
- 无权限；
- 版本冲突；
- 未保存离开；
- 工具或网络异常。

失败后应说明用户已有输入是否保留、如何重试、是否允许跳过、是否需要联系管理员。

### 步骤 6：案例串联

至少一个完整案例，不能只是截图集合。案例应包含任务背景、输入材料、每一步操作、检查点、最终产物和常见错误。

### 步骤 7：排版和 QA

- 正文宋体，标题黑体或宋体加粗；正式中文商务风格。
- 图片与对应文字同页或紧邻；避免孤立标题和大面积空白。
- 图号、图名、章节号连续；表格跨页重复表头。
- 不压缩到难以阅读的小字号。
- 生成/修改 DOCX 后必须逐页渲染为 PNG，全页检查截图清晰度、表格断裂、文字截断、页眉页脚和图注。

## 6. 图注规范

格式：`图 X-X：页面/操作名称`

图前说明用途，图后说明关键区域或结果。需要标注时使用编号、箭头或边框，但不得遮挡原始信息。

## 7. 常见问题规范

每个问题按以下结构：

- 问题现象；
- 可能原因；
- 处理步骤；
- 注意事项；
- 仍未解决时的升级路径。

## 8. 红线

- 只有功能介绍，没有完整操作路径；
- 只放截图，不说明点击位置、输入内容和预期反馈；
- 使用不存在的菜单、按钮、字段或页面；
- 跳过保存、提交、审批、导出、Git 或版本环节；
- 为美化而改变原手册版式；
- 动图加载失败后直接删除；
- 图文不对应或步骤顺序错误；
- 原型截图与真实截图混用却不标识；
- 最终文件未渲染检查。
