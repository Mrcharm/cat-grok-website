# 《鲜花》背景音乐设计

## 目标

移除可见的网易云歌单面板，将背景音乐固定为回春丹乐队《鲜花》。页面加载后立即尝试播放；顶部音乐按钮默认表示音乐已开启，点击后停止，再次点击恢复。

## 交互

- 使用网易云官方单曲 `2086327879`，播放器类型为单曲 `type=2`。
- 播放器 iframe 对用户不可见，不展示歌单、外链或“点击开启”面板。
- 首次加载设置单曲地址并携带 `auto=1`。
- 浏览器拦截自动播放时，用户第一次点击或按键后自动重建单曲 iframe，再次尝试播放。
- 用户主动点击音乐按钮停止后，不再因页面交互自动恢复；再次点击音乐按钮才恢复。
- 四个站内页面沿用现有无刷新导航，公共外壳不替换，音乐不中断。
- 按钮使用 `aria-pressed` 和动态 `aria-label` 表达“停止背景音乐：《鲜花》”或“播放背景音乐：《鲜花》”。

## 边界

- 不下载、不提交、不盗链歌曲音频文件。
- 不声称浏览器一定允许首次有声播放；只能在浏览器规则允许时自动播放，并在首次用户交互时重试。
- 本次不修改 JARVIS 回复朗读音色，作为后续独立问题处理。

## 验收

- 四页生成 HTML 均不包含可见音乐面板或旧歌单 ID `885054268`。
- 四页均包含隐藏的《鲜花》单曲 iframe 与音乐开关。
- 自动测试覆盖默认播放、主动停止、再次播放、首次交互重试和主动停止后不重试。
- 全量 `pnpm check` 通过，并在本地真实页面验证按钮状态和跨页连续性。
