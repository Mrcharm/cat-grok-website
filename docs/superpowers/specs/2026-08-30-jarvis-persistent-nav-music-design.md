# JARVIS 固定导航与连续音乐设计

## 目标

优化首页、文章、技能、作品集四个公开页面，使它们共享完全一致的顶部导航，并在站内切页时持续播放网易云歌单 `885054268`。

成功标准：

- 四页顶部均固定显示：左侧品牌圆点与 `MR.C JARVIS`，右侧首页、文章、技能、作品集和音乐入口。
- 切换当前页面时，只改变导航项的选中视觉，不改变品牌、导航项、音乐按钮的位置和尺寸。
- 点击站内导航后不整页刷新，地址栏、前进、后退和直接访问各页面仍正常。
- 网易云播放器仅创建一次，站内切页不销毁、不暂停、不从头加载。
- 首次进入网站立即尝试有声播放；被浏览器策略拦截时，出现一次清楚的“点击开启音乐”提示，首次用户交互后再次播放。
- 网易云播放器自身失效时，页面明确提示并提供在网易云打开歌单的入口。

## 已确认的根因

### 导航跳动

首页使用 `.topbar` 和 `.nav`，其他页面使用 `.site-header` 和缺少 `.nav` 类的 `#site-nav`。因此首页的 `.nav a` 样式没有完整应用到子页面。线上实测首页导航宽约 238px，子页面为 144–158px；选中项文本宽度不同会进一步推动整个导航组移动。

页面是否出现纵向滚动条也会改变可用视口宽度，造成约一个滚动条宽度的横向变化。

### 音乐无法播放

当前播放器使用延迟加载，地址参数为 `auto=0`，因此首次进入不会加载或播放。线上点击后，网易云歌单能够显示，但播放时间停在 `00:00`，同时出现网易云旧版外链播放器的跨域安全错误。

即使改为 `auto=1`，浏览器仍可能拦截没有用户手势的有声自动播放。这是浏览器控制的行为，网站不能可靠绕过。

## 总体方案

采用“静态多网址 + 渐进增强的无刷新站内导航”。

每个网址继续输出完整 HTML，保证刷新、复制链接、搜索引擎访问和脚本失败时仍可正常浏览。JavaScript 可用时，公共导航拦截四个站内入口，获取目标 HTML，仅替换 `<main>` 内容和页面元数据。顶部导航、音乐按钮、播放器 iframe 始终留在当前文档中。

不把四页内容全部塞进首页，也不通过弹窗保存播放器。

## 组件设计

### 1. 唯一顶部外壳

生成器提供唯一的页头结构，首页和三个子页面不得再手写不同版本：

- `.site-header`：固定顶部，高度、左右内边距和边框保持一致。
- `.brand`：品牌圆点、`MR.C`、`JARVIS` 三部分结构固定。
- `#site-nav.nav`：四个导航项顺序和尺寸固定。
- `.music-btn`：与导航处于同一个右侧容器。
- `.music-panel`：位于页头之外、`main` 之前，不随主体替换。

当前项只允许改变颜色、边框和背景；不得改变字体粗细、内边距、字号或占位宽度。桌面端启用 `scrollbar-gutter: stable`，避免不同页面是否出现滚动条造成横向跳动。

移动端沿用菜单按钮，但打开和关闭菜单不得改变桌面端 DOM 结构。页头固定后，主体统一预留页头高度，避免内容被遮挡。

### 2. 无刷新导航控制器

`site.js` 负责：

1. 识别首页、文章、技能、作品集四个同源链接。
2. 点击后获取目标 HTML，解析目标 `<main>`、标题、描述和 body 页面类。
3. 获取成功后一次性替换当前 `<main>`，更新 `document.title`、描述、canonical、地址栏和导航选中态。
4. 触发统一的 `jarvis:page-ready` 事件，初始化新主体中的页面功能。
5. 监听 `popstate`，让浏览器前进和后退使用同一加载流程。
6. 新页面加载完成后滚动到顶部，并把焦点移到主标题，兼顾键盘和读屏用户。

导航期间设置加载状态并避免重复点击。网络失败、解析失败或目标不是受支持页面时，退回普通整页跳转，确保功能不被 JavaScript 锁死。

### 3. 页面功能生命周期

文章筛选和技能页面交互改为可重复调用的初始化函数。它们在首次加载及每次 `jarvis:page-ready` 后执行，并使用初始化标记避免重复绑定事件。

首页 JARVIS 对话、语音和粒子动画仅在首页主体存在时启动；离开首页时停止仅属于首页的动画循环、定时器和语音任务，返回首页后重新初始化。音乐播放器不属于首页生命周期，不被清理。

### 4. 音乐状态机

音乐有四种明确状态：

- `loading`：创建 iframe，使用歌单 `885054268` 和 `auto=1` 尝试立即播放。
- `ready`：iframe 已加载，表示播放器可见，不表示已经发出声音。音乐按钮不得用动态声波伪装实际播放状态。
- `needs-gesture`：首次加载 1.5 秒后显示轻量提示“没听到音乐？点击开启”。用户点击提示时，在该用户手势处理函数内重新创建 `auto=1` 的 iframe，然后隐藏提示并在当前会话记录已经尝试解锁。
- `unavailable`：iframe 触发加载错误或超过 10 秒仍未加载，显示“网易云播放器暂不可用”，并提供官方歌单链接。

由于跨域 iframe 无法可靠读取其真实音频状态，站点不得声称或检测“正在播放”。1.5 秒提示是一项恢复入口，不是对播放失败的判定；如果用户已经听到音乐，可以直接忽略。

用户手动关闭音乐后，在当前会话内记住关闭状态；后续站内切页不得再次强制打开。刷新或新会话时重新尝试自动播放。

## 数据流

```text
首次访问完整静态页
  -> 创建公共页头与网易云播放器
  -> 尝试 auto=1
  -> 成功则保持播放器
  -> 被拦截/失效则显示一次交互提示

点击站内导航
  -> 获取目标完整 HTML
  -> 解析并替换 main 和页面元数据
  -> 更新 URL、当前导航项、页面初始化函数
  -> 公共页头和音乐 iframe 不变
```

## 错误与边界

- 无 JavaScript：四个网址仍按普通静态页面工作，音乐会随整页切换中断。
- 自动播放被禁止：必须接受一次用户交互，不尝试规避浏览器安全策略。
- 网易云跨域播放器失效：展示故障状态和歌单外链，不伪装成功。
- 获取目标页面失败：直接跳转到原链接。
- 快速连续点击：只接受最后一次导航结果，旧请求被取消或丢弃。
- 外部链接、下载链接、带修饰键点击和新窗口操作：不拦截。
- 直接访问 `/articles/` 等网址：渲染完整页头和主体，然后接管后续站内导航。

## 测试设计

先增加失败测试，再实现功能：

1. 静态契约测试：四个公开页面输出相同页头结构、相同导航顺序、相同音乐歌单 ID。
2. 样式契约测试：页头固定，导航项尺寸不会因选中态改变，启用稳定滚动条占位。
3. 导航单元测试：只替换 `<main>`；页头节点和音乐 iframe 节点身份保持不变。
4. 历史记录测试：点击、前进、后退更新 URL、标题、选中态和主体。
5. 降级测试：目标获取或解析失败时执行普通跳转。
6. 生命周期测试：文章、技能和首页功能切入后初始化，切出后不残留重复监听或动画。
7. 音乐测试：首次使用 `auto=1`；被拦截后显示交互提示；用户关闭状态跨站内切页保持。
8. 浏览器验收：在桌面和移动宽度依次切换四页，记录品牌、导航和音乐按钮的坐标，允许的误差不超过 1px。

## 不在本次范围

- 绕过浏览器自动播放策略。
- 抓取、代理或重新分发网易云受版权保护的音频文件。
- 重做四页主体视觉、文章内容、技能内容或作品集内容。
- 把 JARVIS 对话原型接入真实大模型或长期记忆服务。

## 失效条件

如果网易云外链播放器在用户完成一次交互后仍无法播放，则“指定网易云歌单直接嵌入并连续播放”在当前技术来源下不可交付。此时应保留连续导航架构，把音乐降级为网易云歌单入口，或由用户另行提供具备公开播放授权的音频源；不能通过复制网易云音频规避限制。
